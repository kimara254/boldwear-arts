# BoldWearArts

**Contemporary African Art** by Simon Kaguru Kimara.

BoldWearArts is an independent art practice exploring cultural memory, ancestral knowledge, landscapes, lived histories and contemporary African identity. The website presents selected works, editorial context, in-room previews and links to fine-art print editions through Pictorem.

## Website

- Live site: https://kimara254.github.io/boldwear-arts/
- Fine-art gallery and print ordering: https://www.pictorem.com/gallery/BoldWearArts.Collective
- Artist: Simon Kaguru Kimara

## Features

- Responsive editorial homepage and artist statement
- Artwork catalogue loaded from `gallery.json`
- Search and series filters
- Artwork, Gallery Room, Sunlit Loft and Salon Lounge previews
- Collector shortlist saved in the visitor's browser
- Direct links to Pictorem for print configuration and ordering
- Search/social metadata and canonical URL

## Project files

- `index.html` — site structure, metadata and editorial content
- `style.css` — visual identity and responsive layout
- `app.js` — catalogue, filters, previews and shortlist interactions
- `gallery.json` — public artwork catalogue
- `assets/artworks/` — artwork image files
- `assets/mockups/` — interior presentation images

## Publishing

The site is a static GitHub Pages website. Keep the repository's GitHub Pages source pointed at the `main` branch and the repository root.

When adding an artwork, add its image and room-preview assets, then add a matching record to `gallery.json`. Use the artwork's own Pictorem product URL whenever one exists; do not use an unrelated product link.

## Brand direction

The visual identity uses a restrained gallery palette, warm mineral and earth tones, editorial serif typography and spacious layouts. The positioning is contemporary African art — not generic African-inspired décor. Text should remain accurate to each artwork and avoid invented provenance, cultural claims, dimensions or sales figures.
